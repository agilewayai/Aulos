# Listening Guide Eval

## When to use

After compose, before showing the guide as final (or to annotate caveats).

## Rubric (0–2 each, pass ≥ 8/10)

| Criterion | 0 | 1 | 2 |
| --- | --- | --- | --- |
| Specificity | Vague praise | Some named landmarks | Concrete sections/textures/intervals |
| Ear-actionability | No listening verbs | Occasional cues | Map + practice with clear actions |
| Source hygiene | Myth as fact | Mixed | Legends labeled; uncertainty visible |
| Structure | Unordered dump | Partial chambers | Salon Codex chambers + bilingual + ambient |
| Craft | Ugly/unreadable | Readable | Professional page hierarchy + portrait when available |

## Hard gates (fail regardless of soft score)

- Missing ambient player (`id="aulos-ambient"` or `data-ambient-player`) → **fail**
- Corpus/synthesize hit without EN+ZH panes → note + structure penalty

## Procedure

1. Score the five criteria.
2. Apply hard gates (ambient required).
3. If fail: list concrete revision notes for compose retry.
4. Always return notes even on pass (continuous improvement).

## Anti-patterns

- Passing guides that only summarize Wikipedia tone
- Failing guides solely for missing live web citations when corpus is solid
- Passing corpus flagship guides that omit interpretations/media shelf
- Passing silent pages (no ambient) that look complete in headings alone
