# Iteration Planning

Use this directory for iteration plans, sprint plans, and slice sequencing artifacts.

## Recommended naming

- `ITER-*`
- `iteration-plan-*`
- `sprint-plan-*`

## Each artifact should make clear

- iteration goal
- entry and exit criteria
- sequence of slices
- owner and review date
